# Price & Quantity Calculator 🧮

A simple Streamlit app I built to make quick grocery unit conversions. It helps calculate total cost when buying by grams, or figure out how much quantity you get for a set amount of money.

## What it does

- Calculate Price: Input rate/kg and weight in grams to see total cost.
- Calculate Quantity:Input rate/kg and your budget to see how many grams you get.
